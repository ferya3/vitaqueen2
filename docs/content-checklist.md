# چک‌لیست محتوا و رسانه (فاز ۴)

سایت با محتوای اولیه کامل کار می‌کند، اما موارد زیر **باید با داده واقعی کارخانه** جایگزین شوند. هیچ‌کدام از اعداد زیر نباید توسط طراح یا برنامه‌نویس حدس زده شود.

## اعداد و داده‌های فنی (پنل مدیریت)

- [ ] **تنظیمات ← شاخص‌های کلیدی**: ظرفیت تولید روزانه، سال تأسیس (تیک «نمونه» را بردارید). تعداد محصولات و خطوط تولید خودکار است.
- [ ] **خطوط تولید**: ظرفیت اسمی هر خط (بطری در ساعت) از پلاک دستگاه، سایزهای واقعی، عکس خط.
- [ ] **محصولات**: pH، TDS و ترکیب املاح **از آخرین گزارش رسمی آزمایشگاه**؛ تعداد در بسته، بسته در پالت، ماندگاری، بارکد.
- [ ] **گواهینامه‌ها**: فقط مدارکی که واقعاً دارید؛ شماره، تاریخ صدور/انقضا، اسکن تصویر و PDF. موارد دیگر را غیرفعال کنید.
- [ ] **اطلاعات تماس**: نشانی دقیق، مختصات نقشه، تلفن‌ها، ایمیل‌ها، ساعات کاری، شبکه‌های اجتماعی.
- [ ] **درباره ما**: متن معرفی، مالکیت، تاریخچه (رویدادهای سال‌به‌سال در بخش timeline صفحه about).
- [ ] **نام برند و نام حقوقی** (پیش‌فرض از نام مخزن «VitaQueen» برداشته شده است).

## رسانه (عکاسی و ویدیو صنعتی)

| مورد | مشخصات پیشنهادی |
|---|---|
| عکس محصول (هر SKU) | پس‌زمینه سفید/شفاف، PNG یا WebP، حداقل 1600px ارتفاع، نمای روبه‌رو + زاویه ۴۵° |
| ویدیوی Hero | ۸–۱۵ ثانیه، بی‌صدا، حلقه‌ای، 1920×1080، MP4 (H.264) زیر ۶ مگابایت + تصویر Poster |
| خط تولید | عکس افقی 16:9 از هر خط و هر مرحله (منبع، فیلتراسیون، پرکنی، لیبل، بسته‌بندی، آزمایشگاه) |
| رندر سه‌بعدی (اختیاری) | فایل GLB بطری با لیبل واقعی برای جایگزینی بطری رویه‌ای |
| لوگو | SVG رسمی برند (جایگزین `frontend/public/brand/logo.svg` و `app/icon.svg`) |

## پس از ورود محتوا

```bash
cd frontend && API_INTERNAL_URL=https://<domain>/api/v1 npm run snapshot
```

Snapshot را commit کنید تا buildهای بعدی هم محتوای واقعی داشته باشند.
